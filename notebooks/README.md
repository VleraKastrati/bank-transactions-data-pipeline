# Bank Transactions Data Pipeline

This project demonstrates an end-to-end data pipeline built with Databricks, PySpark, Delta Lake, and SQL.

## Project Notebooks

- `01_generate_bank_data` – Generates sample bank transaction data.
- `02_bronze_transactions` – Stores raw transactions in the Bronze layer.
- `03_silver_transactions` – Cleans and validates transaction data.
- `04_gold_transactions` – Creates aggregated transaction summaries.
- `05_sql_analysis` – Performs SQL queries for data analysis.

## Technologies

- Databricks
- PySpark
- Delta Lake
- SQL
- Databricks Jobs
